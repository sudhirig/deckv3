# AI-Powered Digital Family Office - React Presentation

## Overview
This project is a 28-slide React presentation showcasing an AI-powered digital family office platform designed for high-net-worth investors. The platform aims to redefine wealth management through advanced AI, offering personalized financial solutions, enhanced alpha generation, and seamless integration for complex financial needs, particularly in emerging markets like India (GIFT City). The presentation features a modern UI, smooth animations, and professional design, with a strong emphasis on user experience and visual appeal. The business vision is to capture a significant share of the evolving wealth management landscape by providing a superior, data-driven, and highly automated alternative to traditional family offices.

## User Preferences
- Ultra-modern graphics and world-class design
- PDF exportable presentation
- Professional animations and transitions
- Clean, readable typography
- Data-driven visualizations

## System Architecture
The presentation is built with React 18 and Vite 5 for a fast and efficient development experience. Framer Motion is used for professional animations and transitions, providing a smooth and interactive user experience. The UI/UX features a glassmorphism design with teal/green gradient accent colors, optimized for a dark theme and 16:9 presentation format. Each slide is an independent React component, promoting modularity and reusability. A key architectural decision was to use React over Slidev for better reliability within the Replit environment. Print CSS is extensively used to enable high-quality, browser-native PDF exports without external dependencies. The system prioritizes responsive design, keyboard navigation, and a consistent visual language with professional iconography (Lucide React) and animated components like `AnimatedCounter`, `CircularProgress`, and `InteractiveCard`. The "Mother Deck" plan outlines an expansion to 50+ slides, incorporating new components for investor snapshots, persona vignettes, competitive analysis, and detailed financial metrics, aiming for a comprehensive and modular presentation framework.

## External Dependencies
- **React 18**: Frontend UI library
- **Vite 5**: Build tool
- **Framer Motion**: Animation library
