## 🎨 EXACT Visual Style Specifications

### From Arta's unnamed.png:

**Color Palette:**
```css
/* Arta uses warm, friendly colors */
--arta-orange: #F97316;      /* Headers, accents */
--arta-blue: #3B82F6;        /* Links, buttons */
--arta-teal: #14B8A6;        /* Success states */
--arta-cream: #FDF6E3;       /* Backgrounds */
--arta-white: #FFFFFF;       /* Cards */
--arta-gray: #64748B;        /* Body text */
--arta-dark: #1E293B;        /* Headlines */
```

**Typography:**
- **Headlines:** Bold, friendly sans-serif (Inter/Rotunda style)
- **Body:** Regular weight, high readability
- **Icons:** Colorful, rounded, friendly (not sharp/corporate)

**Layout:**
- **Grid:** 2-column asymmetric layout
- **Cards:** Rounded corners (16-24px)
- **Spacing:** Generous whitespace
- **Shadows:** Soft, subtle (no harsh edges)

**Iconography:**
- Colorful filled icons (not outline)
- Rounded shapes
- Friendly mascot/character
- Emoji-style simplicity
