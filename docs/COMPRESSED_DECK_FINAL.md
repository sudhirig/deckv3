## 🎨 Design System Used

### Colors
- **Teal:** `#14B8A6` (primary accent)
- **Purple:** `#8B5CF6` (secondary)
- **Amber:** `#F59E0B` (highlights/warnings)
- **Pink:** `#EC4899` (special callouts)
- **Blue:** `#3B82F6` (links/CTAs)
- **Green:** `#10B981` (success/positive)

### Icons
All icons from `lucide-react`:
- `Gem`, `Globe`, `Rocket`, `Building2`, `BarChart3`, `Code2`
- `Brain`, `TrendingUp`, `Shield`, `Zap`, `Users`, etc.

### Animations
All animations via `framer-motion`:
- `initial`, `animate`, `transition` props
- `whileHover` for interactive feedback
