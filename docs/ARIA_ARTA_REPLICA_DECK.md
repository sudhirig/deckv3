## 🎨 DESIGN SYSTEM

### Colors (Match Arta's warm palette)
```css
--background: #FDFBF7;      /* Warm cream */
--card-bg: #FFFFFF;          /* White cards */
--text-primary: #1A1A1A;     /* Near black */
```

- **Headlines:** Serif font (elegant, like Arta)
- **Body:** Sans-serif (clean, readable)
- **Style:** Minimal, lots of whitespace

### Visual Style
- Light cream backgrounds
- Subtle shadows on cards
- Line icons (not filled)
- Elegant photography
- 3D abstract elements
