## 🎨 UI/UX TRANSFORMATION GUIDELINES

### **Color Psychology for Fintech:**
```
PRIMARY PALETTE:
- Trust Blue: #0066CC (IBM/Stripe blue)
- Wealth Gold: #FFB800 (subtle luxury)
- ARIA Teal: #14B8A6 (unique identifier)
- Success Green: #00A86B (growth/profit)

USAGE:
- Problems: Red/Orange tones
- ARIA Solutions: Teal/Blue tones
- Outcomes: Green/Gold tones
```

### **Typography Hierarchy:**
```
TITLE: 48-64px - Bold - 5-7 words max
SUBTITLE: 24-32px - Medium - One line
BODY: 18-20px - Regular - 3 bullets max
DATA: 36-48px - Bold - Hero metrics
CAPTION: 14-16px - Light - Sources/notes
```

### **Animation Principles:**
```
ENTRANCE: Fade up (0.3s ease-out)
TRANSITIONS: Morph between states
EMPHASIS: Subtle pulse on key data
INTERACTION: Hover states on all clickable
BACKGROUND: Slow particle movement (30s loops)
```

### **Layout Patterns:**
```
HERO LAYOUT: 60% visual, 40% text
COMPARISON: Split screen with clear divide
DATA STORY: Chart with 3 annotation points
PROCESS: Linear flow with progress indicator
PROOF: 3-column evidence grid
```
