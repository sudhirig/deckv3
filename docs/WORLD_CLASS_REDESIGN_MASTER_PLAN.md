## 🔒 DESIGN PRINCIPLES

### Visual Hierarchy
1. **Primary:** Main message/data
2. **Secondary:** Supporting points
3. **Tertiary:** Additional context

### Color Usage
- **Teal (#14b8a6):** Primary actions, success
- **Cyan (#06b6d4):** Secondary, links
- **Emerald (#10b981):** Metrics, positive
- **Dark (#0a0f1b):** Backgrounds
- **Light (#e2e8f0):** Text

### Typography Scale
```css
Display: clamp(3rem, 5vw, 4rem)
H1: clamp(2rem, 3vw, 2.5rem)
H2: clamp(1.5rem, 2vw, 2rem)
Body: clamp(1rem, 1.2vw, 1.25rem)
Small: 0.875rem
```

### Animation Standards
```jsx
Entry: fadeIn + scale(0.95 → 1)
Hover: translateY(-2px)
Duration: 0.3s-0.5s
Easing: cubic-bezier(0.4, 0, 0.2, 1)
```

### Spacing System
```css
xs: 0.5rem (8px)
sm: 1rem (16px)
md: 1.5rem (24px)
lg: 2rem (32px)
xl: 3rem (48px)
2xl: 4rem (64px)
```
