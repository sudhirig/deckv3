# ARIAwealth.ai Brand Guidelines

## Logo Design
The ARIAwealth.ai logo represents the convergence of AI technology and wealth management expertise.

### Logo Elements
1. **Hexagon Shape**: Represents technology, structure, and the systematic approach of AI
2. **Neural Network Dots**: Six connection points symbolizing the interconnected AI specialists
3. **"A" Symbol**: Central element representing ARIA at the core
4. **Gradient Colors**: 
   - Primary: #14b8a6 (Teal) - Trust and stability
   - Secondary: #06b6d4 (Cyan) - Innovation and technology
   - Accent: #10b981 (Emerald) - Growth and prosperity

### Logo Variations
- **Full Logo**: Icon + "ARIAwealth.ai" text
- **Icon Only**: Hexagon with A symbol
- **Text Only**: "ARIAwealth.ai" with gradient

## Website Domain
**Primary**: ARIAwealth.ai
- Modern .ai domain emphasizing AI-first approach
- Clean, memorable, professional

## Typography
- **Logo Font**: System UI, -apple-system (clean, modern)
- **ARIA**: Bold weight, gradient fill
- **wealth**: Regular weight, gray (#64748b)
- **.ai**: Bold weight, gradient or cyan

## Color Palette

### Primary Colors
- **Teal**: #14b8a6 (Primary brand color)
- **Cyan**: #06b6d4 (Technology accent)
- **Emerald**: #10b981 (Success/growth)

### Background Colors
- **Deep Navy**: #0a0f1b (Primary dark)
- **Dark Slate**: #0f172a (Secondary dark)
- **Slate**: #1e293b (Tertiary dark)

### Text Colors
- **White**: #ffffff (Headers on dark)
- **Light Gray**: #e2e8f0 (Primary text)
- **Medium Gray**: #94a3b8 (Secondary text)
- **Dark Gray**: #64748b (Subtle text)

## Usage Guidelines

### Logo Placement
- Top-left corner for navigation/headers
- Center for splash screens and loading states
- Maintain minimum clear space equal to the height of the hexagon

### Logo Sizing
- Minimum size: 32px height (icon only)
- Recommended header size: 40px height
- Hero/splash size: 72px height

### Logo Don'ts
- Don't rotate or skew the logo
- Don't change the colors
- Don't add effects (shadows, outlines) unless specified
- Don't place on busy backgrounds without proper contrast

## Animation Guidelines
- Logo reveal: Scale from 0 to 1 with ease-out
- Hexagon rotation: 360° over 20 seconds (subtle, continuous)
- Neural dots: Scale pulse on initial load
- Text reveal: Stagger left-to-right

## Web Properties

### Favicon
- Use the icon-only version
- SVG format preferred for scalability
- Include .ai text for larger favicon sizes

### Social Media
- Use full logo on light backgrounds
- Use icon only for profile images
- Maintain gradient colors when possible

## Voice & Tone
- **Professional**: Institutional-grade language
- **Innovative**: Emphasize AI capabilities
- **Trustworthy**: Focus on security and results
- **Accessible**: Explain complex concepts simply

- Secondary: "She Orchestrates Wealth Like No Human Can"
