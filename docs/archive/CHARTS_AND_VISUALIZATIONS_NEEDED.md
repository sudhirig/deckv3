## 🛠️ IMPLEMENTATION GUIDE

### **Design Tools Recommended:**

#### **For Static Charts:**
- **Primary:** Figma or Adobe Illustrator
- **Data:** Excel → Figma plugin
- **Colors:** Brand palette only

#### **For Animated Charts:**
- **Primary:** After Effects + Bodymovin
- **Web:** D3.js or Chart.js
- **Export:** Lottie for web, MP4 for slides

#### **For Interactive:**
- **Prototype:** Framer or Principle
- **Production:** React + Framer Motion
- **Fallback:** Static image for PDF

## 📊 DATA VISUALIZATION BEST PRACTICES

### **Rule of 3:**
- Maximum 3 data series per chart
- Maximum 3 key points highlighted
- Maximum 3 seconds to understand

### **Cognitive Load:**
- Start with overview, zoom to detail
- Use animation to guide attention
- One message per visualization

### **Accessibility:**
- High contrast ratios (4.5:1 minimum)
- No color-only communication
- Clear labels, not just legends

### **Mobile-First:**
- Test all charts at 320px width
- Ensure text remains readable
- Touch targets for interactive elements
