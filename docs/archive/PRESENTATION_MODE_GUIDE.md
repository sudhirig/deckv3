Your deck is now optimized for **full-screen presentations** and **PDF exports**.

| Shortcut | Action |
|----------|--------|

## 🚀 How to Present

### 1. Enter Presentation Mode
```
1. Open your deck in browser
2. Press Ctrl+P (or click "🎯 Present" button)
3. Deck automatically enters fullscreen
4. Fonts and layouts optimize for projection
```

### 2. Navigate Slides
```
- Use arrow keys or slide navigator
- All content fits without scrolling
- Animations play automatically
- No mobile/responsive issues
```

### 3. Export to PDF
```
1. Press Ctrl+E
2. Choose "Save as PDF" in print dialog
3. Settings:
   - Layout: Landscape
   - Paper: A4 or Letter
   - Margins: Minimal
   - Background graphics: ✓
```

## 🛠️ Troubleshooting

### Issue: Content Cut Off
**Solution**: You're likely below 1366px width. Enter fullscreen mode (F11).

### Issue: Text Too Small
**Solution**: Press Ctrl+P to enable presentation mode for larger fonts.

### Issue: PDF Missing Backgrounds
**Solution**: Enable "Background graphics" in print dialog.

### Issue: Animations in PDF
**Solution**: Normal - animations are automatically removed for print.
