### Navigation Methods:

1. **Direct URL**: 
   - Type `http://localhost:3001/#/slide/92` in your browser
   - Change the number (92-107) to navigate between slides

2. **Keyboard Navigation**:
   - Press → (right arrow) to go to next slide
   - Press ← (left arrow) to go to previous slide
   - Jump to slide 92 to start the new slides

3. **Thumbnail View**:
   - Press 'T' key to see all slide thumbnails
   - Scroll down to slides 92-107
   - Click on any thumbnail to view

4. **Dropdown Menu**:
   - Use the dropdown in top navigation
   - Scroll to find slides 92-107
   - They are named:
     - "The AI Revolution is Here" (92)
     - "The Perfect Storm" (93)
     - "The Advisor Extinction Event" (94)
     - etc.

### Troubleshooting:

If slides don't appear:
1. Make sure dev server is running: `npm run dev`
2. Refresh browser (Cmd+R or F5)
3. Clear browser cache if needed
4. Check console for errors (F12)

The slides start at position 92 in the deck array (after all appendix slides).
